## ORIENTAÇÕES

- \- Esta avaliação é individual.

- \- A avaliação deve ser ser entregue no dia (24/11/2026) até as 19:00, nesta aula cada aluno deverá apresentar individualmente ao professor seu trabalho rodando no computador. Durante a apresentação o professor fará perguntas para comprovar o seu entendimento sobre o que foi desenvolvido, inclusive pode ser solicitado alterações no código durante a apresentação.

- \- O projeto deve ser publicado no GitHub e o link do seu repositório deve ser postado no portal dentro da Avaliação que será disponibilizada na seção do dia (Aula 24/11).

- \- Não é necessário publicar no GitHub Pages, pois o PHP não vai rodar no Git.

- \- Você deve exportar o seu banco de dados através do phpMyAdmin e adicionar no repositório do seu projeto o arquivo contendo os scripts do seu banco de dados.

- \- Conforme o trabalho A1.1 que todos realizaram neste semestre desenvolvendo um web site para um segmento de prestação de serviços, nesta avaliação cada aluno deve utilizar o site já desenvolvido para implementar as seguintes alterações:

- \* Você deve escolher três seções do seu site: (Orçamento, Contato, Depoimentos, Serviços ou Blog)

- \* Para cada uma das seções escolhidas você deverá criar um tabela no seu banco de dados com os campos necessários para armazenar as informações.

- \* Deve implementar as rotinas necessárias para fazer o insert das informações na tabela do seu banco de dados ou deve implementar a rotina para exibir os dados gravados na tabela do seu banco de dados.

- \* Não pode implentar somente funcionalidades de listagem ou somente de inserção, é obrigatório pelo menos uma funcionalidade de cada tipo.

## DETALHES DAS FUNCIONALIDADES CONFORME AS SEÇÕES ESCOLHIDAS

Orçamento: seu site já tem um formulário para solicitar orçamentos, portanto ao clicar no botão de confirmação os dados devem ser enviados para o back-end e gravados na tabela de orçamentos.

Contato: seu site já tem um formulário para enviar mensagens de contatos, portanto ao clicar no botão de confirmação os dados devem ser enviados para o back-end e gravados na tabela de contatos.

Depoimentos: Hoje seu site já apresenta depoimentos de clientes, porém agora esses depoimentos devem ser


carregados de uma tabela do seu banco de dados.

Depoimentos: Crie também em seu site uma funcionalidade para inserir novos depoimentos, ou seja, um formulário para que o cliente possa enviar o seu depoimento para inserir no seu banco de dados.

Serviços: Seu site já apresenta os serviços prestados, porém agora esses serviços devem ser carregados de uma tabela do seu banco de dados.

Blog: Seu site já apresenta posts, porém agora esses posts devem ser carregados de uma tabela do seu banco de dados.
