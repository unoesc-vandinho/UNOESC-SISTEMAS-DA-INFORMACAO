# UNOESC - Sistemas da Informação

Este repositório reúne os projetos e atividades desenvolvidos durante o curso de Sistemas da Informação na UNOESC. Aqui estão concentrados os trabalhos práticos, exercícios e implementações realizadas ao longo das disciplinas, com foco em desenvolvimento web, lógica de programação e estrutura de dados.

## Objetivo

Centralizar os materiais e projetos do curso em um único local, facilitando o acesso, organização e acompanhamento do aprendizado.

## Projetos e demonstrações

- Piratafilx: https://unoesc-vandinho.github.io/UNOESC-SISTEMAS-DA-INFORMACAO/Desenvolvimento-web/aula_03/projeto_netflix/
- ayla02: https://unoesc-vandinho.github.io/UNOESC-SISTEMAS-DA-INFORMACAO/Desenvolvimento-web/aula_02/

## Estrutura do repositório

- Desenvolvimento-web: projetos de páginas web e interfaces
- Estrutura-de-dados: exercícios e atividades em C++ e Python

## Tecnologias abordadas

- HTML
- CSS
- JavaScript
- Python
- C++

Este repositório serve como registro do progresso acadêmico e dos projetos desenvolvidos ao longo do curso.
